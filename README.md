# AI 제목 + 본문 초안 생성기

주제를 입력하면 네이버 블로그용 후킹 제목 5개와 경험담 톤의 본문 초안을 생성해주는 로컬 웹앱입니다.
자동 게시 기능은 없습니다 — 생성된 초안은 반드시 사실관계를 확인하고 직접 수정한 뒤 본인이 게시해야 합니다.

## 1. Gemini API 키 발급 (무료)

1. https://ai.google.dev/ 접속 → 구글 계정으로 로그인
2. "Get API key" 클릭 → 새 API 키 생성
3. 생성된 키를 복사

## 2. 설치

```bash
cd "naver-blog-generator"
pip install -r requirements.txt
```

## 3. API 키 설정

`.env.example` 파일을 복사해서 `.env` 파일을 만들고, 발급받은 키를 붙여넣으세요.

```
GEMINI_API_KEY=여기에_발급받은_키
```

## 4. 실행

```bash
python app.py
```

브라우저에서 http://localhost:5000 접속

## 사용법

1. 주제/키워드 입력 (예: "여름철 자동차 에어컨 냄새 없애는 법")
2. 톤 선택
3. "초안 생성하기" 클릭
4. 제목 후보와 본문 초안을 확인 → 복사 버튼으로 복사
5. **직접 내용을 검토·수정한 뒤** 네이버 블로그에 게시

## 주의사항

- 생성된 내용에 사실과 다른 정보나 과장된 수치가 없는지 반드시 확인하세요.
- 이미지도 저작권 문제 없는 것(무료 라이선스 이미지, 직접 촬영한 사진)만 사용하세요.
- 이 툴은 초안 작성 시간을 줄이기 위한 보조 도구이며, 자동 대량 게시/매크로 용도로 사용하면 네이버 이용약관 위반으로 계정 제재를 받을 수 있습니다.
